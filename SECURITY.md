# Güvenlik ve veri saklama

Bu depo **public**. Kişisel veriler, ham katılımcı ölçümleri, anket yorumları, kimlik/seri/IP bilgileri, anahtarlar, şifreler, tünel kimlik bilgileri, oturum veya özel makine yapılandırmalarını commit etmeyin.

Kullanıcı kontrolcü verisini yalnız açık rızayla work-pc sunucusuna gönderir; GitHub bu verinin deposu değildir. Serbest yorum alanlarında kişisel veri girilmemesi konusunda kullanıcı uyarılmalıdır; aydınlatma ve silme işleyişleri ayrıca değerlendirilmelidir. Üretim sürücüsü ve gerçek fiziksel düzeltme **onaylı değildir**. Yanlışlıkla anahtar yüklenirse iptal edin ve Git geçmişinden temizlenmesini sağlayın; dosyayı silmek tek başına yeterli değildir.
